Skill reference

Deception

Deception is a skill used for ability checks in relevant situations.

What It Is

Deception is a skill used with Charisma checks when a task matches that area of expertise.

This page is a compact play reference. If a spell, feature, monster, item, or DM ruling gives a more specific instruction, use that specific instruction.

How To Use It

When the DM calls for Deception, roll a d20 and add the relevant Charisma modifier. Add proficiency bonus if you are proficient in the skill.

Limits And Rolls

  • The DM chooses whether a skill applies.
  • Having proficiency helps the roll, but it does not make impossible tasks possible automatically.
  • Expertise or other features can change the bonus.
  • Roll d20 + Charisma modifier + proficiency bonus if proficient.
